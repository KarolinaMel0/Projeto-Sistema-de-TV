# Projeto-Sistema-de-TV
Sistema de gerenciamento de canais e programação de TV desenvolvido em Java, utilizando estruturas de dados como Árvore Binária de Busca (BST), Lista Encadeada e Filas para organização e busca eficiente das informações.

# Sistema de TV

Projeto acadêmico desenvolvido em Java para simular um sistema de gerenciamento de canais de televisão e suas programações.

## Funcionalidades

- Cadastro de canais de TV
- Organização dos canais em uma Árvore Binária de Busca (BST)
- Cadastro de programas para cada canal
- Busca de canais por número
- Busca de programas por título
- Exibição da programação de cada canal
- Controle de programação utilizando fila
- Histórico de programas assistidos

## Estruturas de Dados Utilizadas

### Árvore Binária de Busca (BST)
Utilizada para armazenar os canais de TV de forma ordenada, permitindo buscas eficientes.

### Lista Encadeada
Cada canal possui uma lista encadeada contendo seus programas.

### Fila
Utilizada para controlar a ordem de execução da programação.
